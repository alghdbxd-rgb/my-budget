مشروع «أساس للاستثمار العقاري» — موقع + لوحة عمل
=================================================

التشغيل بأسرع طريقة
-------------------
افتح ملف  index.html  بالنقر المزدوج.

التشغيل الصحيح (يلزم لرفع الفيديو وتثبيت التطبيق على الهاتف)
-------------------------------------------------------------
افتح الطرفية داخل هذا المجلد ونفّذ:

    python3 -m http.server 8000

ثم افتح في المتصفح:  http://localhost:8000

(أو أي خادم ثابت آخر: npx serve  /  php -S localhost:8000  /  Live Server في VS Code)

الصفحات
-------
  index.html    الموقع التسويقي
  offers.html   البحث بين العروض
  app.html      لوحة العمل (العروض، العقارات، نقاط البيع، البكجات، القاصة، المستثمرون، الزبائن، التقارير)

المشروع HTML + CSS + JavaScript خام — بلا أدوات بناء وبلا npm install.
التفاصيل الكاملة وشرح الربط بسيرفر وقاعدة بيانات موجودة في ملف  README.md
