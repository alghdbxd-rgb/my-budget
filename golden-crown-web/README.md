# منصة التاج الذهبي — نسخة HTML + CSS + JavaScript

تطبيق ولوحة تحكم كاملَين لمنصة استشارات طب الأسنان عن بُعد، مبنيان **بـ HTML و CSS
و JavaScript خام فقط** — بلا React، بلا أدوات بناء، بلا `npm install`. يكفي فتح
`index.html` في المتصفح.

> هذا المجلد مستقل تماماً عن تطبيق الميزانية (`my-budget`) في جذر المستودع، وعن
> نسخة المعاينة القديمة المبنية بـ React في مجلد `golden-crown/`.

## التشغيل

افتح `index.html` مباشرة بالنقر المزدوج، أو شغّل خادماً محلياً (أفضل لرفع الصور):

```bash
cd golden-crown-web
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الشاشات

| الملف | الدور | المحتوى |
|---|---|---|
| `index.html` | الموقع التسويقي | العرض، رحلة المستخدم، طلب انضمام طبيب، تسجيل الجهات، قائمة الانتظار، التنبيه القانوني |
| `app.html` | المريض | دخول برقم الهاتف + OTP، استبيان ٤ خطوات مع حفظ تلقائي ومخطط أسنان، رفع صور، دفع، متابعة الحالة، التقرير الطبي القابل للطباعة، أقرب الأطباء وحجز موعد |
| `doctor.html` | الطبيب | صندوق الحالات المسندة، كتابة الرأي مع قوالب جاهزة، تقويم أوقات الزيارة، الحساب المالي، البروفايل |
| `supervisor.html` | المشرف | طابور الاستشارات (الطارئة والمتأخرة أولاً)، إعادة التوجيه، مراجعة الجودة، الشكاوى، أطباء النطاق |
| `dashboard.html` | المشرف العام | **لوحة الإدارة الكاملة** — الإحصائيات، الاستشارات، الجودة، الأطباء، المشرفون، العيادات، المالية، القنوات، المحتوى، قواعد العمل، القرارات المفتوحة، سجل التدقيق |
| `clinic.html` | العيادة الشريكة | التحقق من رمز الخصم وصرفه مرة واحدة |

شريط سفلي أسود يظهر في كل الصفحات للتنقل السريع بين الأدوار ولتصفير البيانات التجريبية.

## بيانات الدخول التجريبية

- **المريض**: أي رقم بصيغة `07XXXXXXXXX` (جاهز: `07701234567`) + رمز التحقق `1234`.
- **الطبيب**: اختر أي حساب من القائمة المعروضة (لا يوجد خادم مصادقة).
- **المشرف والإدارة والعيادة**: دخول مباشر (هوية افتراضية قابلة للتبديل).

## أين تُحفظ البيانات

كل شيء في `localStorage` داخل متصفحك تحت المفتاح `gc-web-v1` — لا خادم ولا قاعدة
بيانات ولا أي اتصال خارجي. عند أول فتح تُولَّد بيانات تجريبية واقعية (٢١٦ استشارة،
١٦٩ مريضاً، ١٠ أطباء، حركات مالية، أكواد مصروفة، زيارات قنوات على مدى ٩٠ يوماً)
لتظهر اللوحة بأرقام حقيقية الشكل. زر «تصفير البيانات» يعيد توليدها.

## بنية الملفات

```
css/app.css            نظام التصميم كاملاً (ألوان، مكوّنات، طباعة التقرير، RTL)
js/store.js            البيانات: النماذج، البذرة التجريبية، القراءة/الكتابة، سجل التدقيق
js/engine.js           المحرك: المطابقة الجغرافية، التصعيد، التسعير، ومؤشرات اللوحة
js/ui.js               أدوات الواجهة + الرسوم البيانية (SVG خام: خطي، أعمدة، أشرطة، حلقة، قمع)
js/page-*.js           منطق كل شاشة
```

لا توجد أي مكتبة خارجية — الرسوم البيانية مكتوبة يدوياً بـ SVG، والخط `Cairo` يُحمَّل
من Google Fonts مع بديل نظامي عند انقطاع الإنترنت.

## تغطية وثيقة المتطلبات

مبني على `PRD.md` في نفس المجلد (مستخرج من وثيقة «مدخلات وثيقة المتطلبات»).

**مغطّى**: FR-1 إلى FR-13، FR-15 إلى FR-26، FR-29 إلى FR-32، FR-36، FR-37،
وقواعد العمل في القسم ٦ ونص التنبيه الإلزامي في القسم ٨ (حرفياً).

**خارج النطاق عمداً** (المرحلة الثانية في القسم ١٠): المكالمات المرئية المباشرة
(FR-14)، بوابة اشتراكات البيانات (FR-33)، بوابة فرص العمل (FR-34)، وحدة الدورات
(FR-35) — تظهر كصفحات تسجيل اهتمام فقط.

**القرارات المفتوحة** (القسم ٩): معروضة كسجل قابل للتحديث داخل اللوحة
(`dashboard.html#/decisions`) مع أثر كل بند على الإطلاق. القيم المستخدمة حالياً
(رسم الاستشارة ١٠٬٠٠٠ د.ع، نسبة الطبيب ٧٠٪، زمن الرد ٢٤ ساعة، الطوارئ ٦٠ دقيقة)
**افتراضية للمعاينة** وقابلة للتعديل من `dashboard.html#/settings` — وتنتظر الحسم
مع العميل.

## ملاحظات أمنية

النسخة للمعاينة فقط: لا يوجد تشفير ولا مصادقة حقيقية، ورمز التحقق ثابت. قبل أي
إطلاق فعلي يلزم باك-إند حقيقي يطبّق NFR-1 إلى NFR-5 (سرية البيانات، التشفير أثناء
النقل والتخزين، عزل الأدوار، مكان الاستضافة، وطبقة الموافقة الصريحة).
