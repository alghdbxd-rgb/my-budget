# مصروفي

تطبيق ويب لإدارة المصروفات والراتب والميزانية الشخصية، مبني بواجهة عربية (RTL) بالكامل.

## المزايا

- **الرئيسية**: رصيد حالي، دخل ومصروف الشهر، نسبة الادخار، ورسوم بيانية للمصروفات والاتجاه الشهري.
- **العمليات**: إضافة/تعديل/حذف عمليات الدخل والمصروف والتحويل بين الحسابات، مع فلترة بالنوع والتصنيف والشهر والبحث النصي، واقتراح تصنيف تلقائي اعتماداً على كلمات الملاحظة.
- **الديون والسلف**: متابعة من مدين لمن (لي / علي)، تسجيل دفعات جزئية، وملخص إجمالي.
- **الملاحظات**: تدوين أي شي مهم (عنوان + محتوى)، تثبيت المهم بالأعلى، بحث، وتلوين للتنظيم.
- **حماية وخصوصية**: خزنة مشفّرة فعلياً (AES-256-GCM) بكلمة مرور خاصة بها لحفظ يوزرات وباسوردات ورموز حساباتك، منفصلة تماماً عن باقي بيانات التطبيق.
- **الميزانيات والتصنيفات**: تحديد سقف شهري لكل تصنيف مصروف مع شريط تقدّم، وإدارة كاملة للتصنيفات (إضافة/تعديل/حذف/لون).
- **التقارير**: تفصيل شهري حسب التصنيف (دخل أو مصروف) مع رسم دائري وجدول نسب، واتجاه 12 شهراً، وتصدير CSV.
- **الإعدادات**: حسابات متعددة (نقد، ماستر، بنك...) مع تحويل بينها، عمليات متكررة تلقائية (كالراتب الشهري)، قفل بكلمة مرور، اختيار العملة، الوضع الداكن/الفاتح، تصدير/استيراد نسخة احتياطية JSON، وإعادة ضبط النظام.

جميع البيانات تُحفظ محلياً على جهاز المستخدم عبر `localStorage` — لا يوجد خادم أو قاعدة بيانات خارجية.

قابل للتثبيت كتطبيق (PWA) على الموبايل وسطح المكتب — يفتح بأيقونة خاصة ويعمل بدون اتصال بعد أول زيارة.

## التقنيات المستخدمة

- React 19 + Vite
- React Router
- Tailwind CSS v4
- Recharts للرسوم البيانية
- lucide-react للأيقونات
- vite-plugin-pwa (تثبيت التطبيق + عمل بدون اتصال)

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
```

الناتج في مجلد `dist/` جاهز للنشر على Netlify (يتضمن المشروع `netlify.toml` وملف `_redirects` لدعم التوجيه من جهة العميل).
